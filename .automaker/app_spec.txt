<project_specification>
  <project_name>convex-cms</project_name>

  <overview>
    A developer-first Convex Component for content management with a built-in React admin playground, flexible RBAC, and AI-ready architecture. This headless CMS runs entirely within a Convex backend, providing content modeling, versioning, publishing workflows, and media management through a sandboxed component architecture with isolated database tables and type-safe APIs.

The component is designed for seamless integration with the Convex AI ecosystem - including @convex-dev/agent for AI-powered content operations, @convex-dev/rag for semantic search and retrieval-augmented generation, and collaborative editing components for real-time multi-user content authoring. By leveraging Convex&apos;s component architecture, it maintains strict API boundaries while enabling powerful composition with other Convex components.

Key architectural goals:
- Provide a complete headless CMS as a drop-in Convex component
- Include a batteries-included Admin UI built with React and TanStack Start
- Offer flexible RBAC with sensible defaults and customization hooks
- Enable AI agents to create, query, and manage content programmatically through tool integrations
- Support content retrieval for RAG pipelines with structured content chunks
- Maintain real-time reactivity across all content queries
- Design for AI-assisted development with clean, predictable patterns
- Expose webhook/event systems for external AI pipeline integrations
  </overview>

  <core_capabilities>
    <capability>Content Type Definition - Define custom content schemas with typed fields (text, rich text, number, boolean, date, reference, media) using Convex validators</capability>
    <capability>Content CRUD Operations - Create, read, update, delete content entries with full validation against type schemas</capability>
    <capability>Content Versioning - Track content history with version snapshots, rollback capabilities, and version comparison</capability>
    <capability>Publishing Workflow - Draft/published state management with scheduled publishing support via Convex scheduler</capability>
    <capability>Media Asset Management - Upload, store, and organize files using Convex File Storage with automatic metadata extraction</capability>
    <capability>Slug Management - Automatic URL-safe slug generation with uniqueness validation per content type</capability>
    <capability>Content Relations - Reference other content entries and media assets with typed relationships and depth-limited resolution</capability>
    <capability>Content Querying - Filter, sort, and paginate content with reactive real-time updates using convex-helpers paginator</capability>
    <capability>Full-Text Search - Search content entries across title and searchable fields using Convex search indexes</capability>
    <capability>Localization Support - Multi-locale content with configurable fallback chains</capability>
    <capability>Flexible RBAC - Built-in roles (admin, editor, author, viewer) with customizable permissions and override hooks for complex authorization logic</capability>
    <capability>Access Control Hooks - Extensible authorization via function handles passed from parent app (since ctx.auth unavailable in components)</capability>
    <capability>Event/Webhook System - Emit events on content changes for external integrations and AI pipeline triggers</capability>
    <capability>Admin UI Playground - Pre-built React admin interface using TanStack Start for content management, media library, and publishing controls</capability>
    <capability>AI Agent Integration - Expose tool-compatible APIs for @convex-dev/agent to manage content programmatically</capability>
    <capability>RAG Pipeline Support - Structure content for retrieval-augmented generation with @convex-dev/rag compatibility</capability>
  </core_capabilities>
